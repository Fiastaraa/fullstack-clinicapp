# AssistDoc Client

React + TypeScript + Vite + Tailwind CSS + Axios + React Router + Lucide.

## Install
```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

`VITE_API_URL=http://localhost:3001/api`

## Build
```powershell
npm run build
```

Client web hanya berisi route staff: Admin, Dokter, Perawat, dan Apoteker. Aplikasi pasien berada pada folder `mobile`.
